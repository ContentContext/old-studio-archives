# Content Context - archived website versions

Static recreations of three past WordPress versions of contentcontext.org.

- `v1/` - 2015-2016 version
- `v2/` - 2017-2019 version
- `v3/` - 2020-2025 version

Each version was rebuilt from Wayback Machine snapshots taken during that period (the page
text and layout are from those snapshots; the live WordPress database was not available, so
these are static copies, not running WordPress sites). Some images were never archived and
are omitted.
